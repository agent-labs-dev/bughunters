# bughunters

`bughunters` is the earlier name of [Bugpatrol](https://github.com/agent-labs-dev/bugpatrol). This package installs the same version of `bugpatrol` and runs it, so the old commands continue to work:

```sh
npx bughunters patrol      # the same as: npx bugpatrol
npx bughunters dashboard   # the same as: npx bugpatrol dashboard
```

Use `bugpatrol` for new setups. See the [documentation](https://github.com/agent-labs-dev/bugpatrol#readme).
